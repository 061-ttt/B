# 設計プロンプト（この README のアプリはこのプロンプトで作った）

音声入力の依頼文を、曖昧さ・矛盾・暗黙の前提を潰したうえで再構成したもの。

---

## 役割

あなたは「小学校社会科の授業設計に通じた教育工学者」と「Cloudflare に精通したフルスタック／3D グラフィックスエンジニア」と「UX デザイナー」を兼ねる。授業で 45 分間、実際に 30 台の端末で使われ、1 回でも止まったら授業が崩れる前提で作る。

## 目的（何のためのアプリか）

小5社会「我が国の農業や水産業における食料生産」水産業単元の**第1時**で、子どもが家から持ってきた魚の値札の「産地」を入力し、クラス全員のデータが 1 枚の立体地図に集まっていく体験を通して、

1. 産地の**分布の特徴**を読み取る（国内／海外、海に面した地域、寒流・暖流、大陸棚）
2. 「なぜその地域に水産業がさかんなのか」という**単元を貫く問い**を自分たちで立てる

ことを支える。結論を教えるアプリではなく、**根拠をもって問いを立てるための道具**にする。

## 学習指導要領との対応（守ること）

- 内容(2)ア(ｲ)：食料生産に関わる人々の工夫・努力を理解する素地として、産地の分布をつかむ
- 内容(2)イ(ｲ)：生産の工程・輸送・価格などに着目して考える（値札＝価格・輸送の入口）
- 内容の取扱い：地図帳・統計などの資料を活用 → 地図・凡例・数で分布を読む
- 見方・考え方：**位置や空間的な広がり**（どこに・どのように広がるか）と**相互関係**（海流・海底地形との関係）
- 授業案図解の「現行案の弱点」を解消する：貼って終わり／分類の視点がない／根拠が言語化されない／まとめだけのワークシート

## 機能要件

| # | 要件 | 受入基準 |
|---|---|---|
| F1 | 立体的な日本地図・世界地図 | WebGL で陸地を押し出し、傾けた視点。ピンチ・ドラッグで回転・拡大。世界地図は日本の教科書と同じ**太平洋中心** |
| F2 | 魚の種類＋産地を入力 → 魚デザインと名前のピンが浮き上がる | 入力後 1 秒以内に該当地点からピンが上昇するアニメーション |
| F3 | 全員のデータを 1 つに集約、件数でピンが大きくなる | 同じ産地の件数に応じてピンが平方根スケールで拡大。他端末の入力がリアルタイムに反映 |
| F4 | 寒流（青）・暖流（赤）が動くアニメーション | 細かい矢印が流れに沿って移動。**潮目（ぶつかる所）は赤と青の両方**で表示 |
| F5 | 海の深さのグラデーション | 大陸棚・大陸斜面・深海・海溝を色で区別し、凡例を出す |
| F6 | 開いた瞬間メモができる | メモ欄は JS 読み込み前の HTML に存在し、表示直後から入力・保存できる |
| F7 | タスクはフリックでステータス管理 | 右フリックで進める／左フリックで戻す（メモ→やること→とりくみ中→できた） |
| F8 | 魚の情報をアコーディオンで | タップで展開し、産地・寒流/暖流・漁法/養殖・旬・「なぜ？」のヒントを表示。地図の絞り込みと連動 |
| F9 | 全画面スケルトンローディング | 初回読み込み中は画面全体の骨組みを表示（メモ欄だけは操作可能） |
| F10 | AI（Workers AI） | 値札の文字列をそのまま入れると魚・産地・天然/養殖を抽出。分布から「問いのたね」を出す（答えは出さない） |
| F11 | ワークシート | 図解の「事実／理由の予想／次に調べたいこと」の 3 欄、文型スターター、印刷対応 |

## 非機能要件

- モバイルファースト（iPhone SE 幅 375px で破綻しない）、タブレット・電子黒板でも見られる
- Liquid Glass UI、黒ベース、アニメーション多用（ただし `prefers-reduced-motion` を尊重）
- 余計なキャッチコピーは一切入れない。ラベルは機能を示す最小限の語
- ネットが不安定でも授業が止まらない：サーバーに届かなければ端末内だけで動く（AI も規則ベースに自動で切り替え）
- 個人情報を集めない：名前は入力させず「班」だけ。データはリセットするまで残す（クラスのリセットは先生の端末だけ）
- 5年生が読める表記（難しい語にふりがな）、色だけに頼らない（矢印・模様・文字も併用）

## 技術制約

- バックエンドは Cloudflare（Workers / Durable Objects / Workers AI）
- 技術選定はすべて理由を書く
- GitHub に公開し、CI でテスト・デプロイ

## 検証（完了の定義）

実ブラウザ（Chrome、モバイル表示）で以下を自動テストし、すべて合格させる。

1. 読み込み直後にメモ欄へ入力でき、再読み込み後も残る
2. スケルトンが表示され、地図の準備後に消える
3. WebGL 地図が描画され、海流の矢印が時間とともに動く（ピクセル比較）
4. 魚と産地を入力するとピンが出る／同じ産地を追加するとピンが大きくなる
5. 国内／海外などで絞り込める
6. フリックでタスクのステータスが進む・戻る
7. 図鑑のアコーディオンが開閉する
8. 2 台の端末（ブラウザコンテキスト）で同じクラスに入ると、片方の入力がもう片方に反映される
9. AI が使えない環境でも値札文字列の解析が規則ベースで動く
10. 横スクロールが発生しない／コンソールエラーがない

## 出力

リポジトリ一式、技術選定理由、教師向けの使い方、テスト結果。
